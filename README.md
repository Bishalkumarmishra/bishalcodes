# Bishal Codes | World-Class Web Engineering & 3D Web Architect

A premium developer portfolio, showcasing high-performance web ecosystems, custom interactive 3D components, and digital client tools.

## Key Features

- **Responsive Architecture**: Frameless image renders, responsive layout components, and full-screen width grid styling optimized for all device sizes.
- **PWA Native Shield Integration**: Progressive Web App configured with static offline asset caching, touch gesture scaling controls, print shield layers, screenshot blur filters, and device notch support.
- **System Administration & Client Portal**: Integrated client verification, secure service configurations, and customizable dynamic settings tabs.

## Project Framework & Tech Stack

- **Core Engine**: Next.js (TypeScript) & React
- **Styles**: TailwindCSS & Custom CSS
- **Backend / Database Integration**: Firebase (Firestore, Authentication)

## Getting Started

### Prerequisites

Ensure you have **Node.js** (v18+) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Bishalkumarmishra/bishalcodes.git
   cd bishalcodes
   ```

2. **Install all dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env.local` file in the root directory and specify your Firebase and Gemini API keys:
   ```env
   NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_key
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
   NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
   
   GEMINI_API_KEY=your_gemini_api_key
   ```

4. **Launch Local Server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000` to view the website.
